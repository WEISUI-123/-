一、如何安装桌面版
示例：首先打开浏览器，例如谷歌等，搜索deeo seek harnrss,点进去官网，选择合适的电脑系统例如Windows 等，等待下载完毕选择安装路径，建议c盘以外其他盘。安装完毕即可

二、如何使用命令行 安装
如果你习惯用命令行，也可以不下载 桌面安装包，直接通过命令行工具完成安装。下面以 Windows 为例，从零开始一步步操作，macOS 和 Linux 的思路基本一致，只是个别命令略有差别。

1. 安装前的准备工作
在开始之前，请先确认电脑上已经具备以下基础环境：

操作系统：Windows 10/11、macOS 12 及以上，或主流 Linux 发行版。
网络：能够正常访问外网，用于下载安装包和依赖。
磁盘空间：建议预留至少 2 GB 可用空间。
权限：Windows 下建议以管理员身份运行命令行，避免安装时权限不足。
2. 打开命令行终端
不同系统打开终端的方式如下：

Windows：按下 Win + R，输入 cmd 后回车；或在开始菜单搜索「PowerShell」并右键选择「以管理员身份运行」。
macOS：打开「启动台」，搜索「终端」（Terminal）并打开。
Linux：使用快捷键 Ctrl + Alt + T，或在应用列表中找到「终端」。
打开后可以先输入下面的命令，确认终端能正常工作：

echo "hello deepseek"

命令行安装通常依赖包管理工具。Windows 用户建议先安装 winget（Win10 1809 及以上系统一般自带），macOS 用户使用自带的 brew，Linux  用户使用 apt 或 yum。

先检查工具是否可用：

# Windows
winget --version
macOS
brew --version
Linux（Debian/Ubuntu）
apt --version

4. 通过命令行安装
确认包管理工具可用后，执行安装命令。下面给出各系统的示例命令，具体包名请以官方文档为准：

# Windows（PowerShell，管理员权限）
winget install --id DeepSeek.Harness -e
macOS
brew install deepseek-harness
Linux（Debian/Ubuntu）
sudo apt update
sudo apt install deepseek-harness

5. 验证是否安装成功
安装结束后，输入下面的命令检查版本号：

deepseek-harness --version

如果终端输出了版本号（例如 1.0.0），说明安装成功。若提示「不是内部或外部命令」，说明环境变量没有生效，可以尝试关闭终端后重新打开，或手动把安装目录加入系统 PATH。

6. 常见问题排查
下载速度慢或超时：可以更换网络环境，或配置国内镜像源后重试。
权限不足：Windows 请以管理员身份运行终端，Linux/macOS 在命令前加 sudo。
命令找不到：检查安装目录是否已加入 PATH，并重新打开终端。
版本冲突：先卸载旧版本，再重新执行安装命令。
完成以上步骤后，你就可以在命令行中正常使用该工具了。后续的配置和使用方法，可以参考官方文档进一步了解。

三、命令行安装和桌面安装的区别
前面分别介绍了桌面版安装和命令行安装两种方式。很多新手会问：这两种方式到底有什么区别，我该选哪一种？下面从几个常见维度做一个对比。

1. 一句话概括
桌面安装：下载安装包，双击运行，按向导点「下一步」完成，全程图形界面操作。
命令行安装：打开终端，输入安装命令，由包管理工具自动下载并配置，全程键盘操作。
2. 核心区别对比
对比维度	桌面安装	命令行安装
操作方式	鼠标点击图形界面，按向导操作	在终端输入命令，键盘操作
上手难度	低，零基础也能完成	中等，需要了解基本命令和终端
安装速度	取决于下载速度，一般较慢	通常更快，可复用本地缓存
依赖处理	安装包一般自带依赖，无需手动处理	由包管理工具自动解析和安装依赖
安装位置	安装时可自定义路径	默认安装到系统标准目录，可配置
升级方式	重新下载新版本安装包覆盖安装	一条升级命令即可完成
卸载方式	通过系统「卸载程序」或控制面板	使用对应的卸载命令
适合人群	普通用户、新手、不熟悉终端的人	开发者、运维人员、需要批量部署的人
3. 各自的优缺点
桌面安装的优点：

全程图形化，操作直观，不容易出错。
安装包通常自带运行环境，兼容性更好。
适合不熟悉命令行的新手用户。
桌面安装的缺点：

每次升级都要重新下载安装包，比较麻烦。
安装包体积较大，下载耗时。
不方便在多台机器上批量部署。
命令行安装的优点：

安装、升级、卸载都只需一条命令，效率高。
依赖自动处理，环境更干净。
方便脚本化和批量部署，适合团队统一环境。
命令行安装的缺点：

需要掌握基本的终端操作和命令。
遇到报错时排查门槛相对较高。
不同系统的命令和包名可能不一致。
4. 该怎么选
只是自己用、想快速装好：优先选择桌面安装，省心省力。
开发者、需要频繁升级或批量部署：推荐命令行安装，长期看更高效。
公司或团队统一环境：建议用命令行安装，配合脚本保证每台机器环境一致。
不确定选哪个：先用桌面安装跑通，熟悉之后再尝试命令行方式。
两种方式最终安装的是同一个工具，功能上没有本质差别，区别主要在操作体验和维护成本上。根据自己的使用场景选择合适的方式即可
